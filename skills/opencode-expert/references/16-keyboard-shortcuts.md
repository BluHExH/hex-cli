# Keyboard Shortcuts

## Overview

OpenCode officially documents configurable keybinds and theme/terminal interactions. Specific
bindings should be copied only after checking the documentation and current TUI source.

## Required documentation fields

- Default binding.
- Action.
- Context/scope.
- Config key.
- Conflict behavior.
- Platform variance.

## Known documented example

Official landing documentation states Tab switches build and plan modes.

## HEX implications
