## Tool card lifecycle
1. Agent emits `print_tool_status(name, "running", detail)` → new ToolCard (or reuse running)
2. Completion emits `ok`/`error`/`skipped` with optional output/error → same card updated
3. Click or Enter/Space toggles expand (args/output/error, truncated)
4. ActivityBar phase follows tool name while running
