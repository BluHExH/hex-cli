# HEX CLI Layout Spec (OpenCode-structure reference)

## Regions (reference image)
1. **Top header** (full width, ~1 row): brand | workspace/branch | model · agent
2. **Left sidebar** (~22–28 cols): Session actions, Workspace path, Context bar, Tools count, Permissions, Recent files, Help/Settings
3. **Center column**:
   - Session tab strip
   - Optional welcome card
   - Conversation (You / HEX messages, nested tool cards)
   - Composer (placeholder, Add Context, Tools, permission chip, Enter)
4. **Right sidebar** (~28 cols): Changes list, Tools Activity, Session Info
5. **Bottom status** (full width): Ready · model · path · shortcut hints

Replace OpenCode marks with HEX / NeonBuild. No OpenCode logo copy.
