# HEX CLI v1.5.0 — TUI Startup ImportError Fix

## Root cause
Stage E added package `hex_cli/context/` (`file_mentions.py`). That **shadowed** the existing module `hex_cli/context.py`, which defined:

- `discover_project_summary`
- `load_key_file_snippets`

Agent startup (`hex_cli/agent/loop.py`) still does:

```python
from hex_cli.context import discover_project_summary, load_key_file_snippets
```

Python resolved `hex_cli.context` to the **package**, whose `__init__.py` only re-exported file-mention helpers — hence:

`cannot import name 'discover_project_summary' from 'hex_cli.context'`

## Fix
1. Move former `hex_cli/context.py` → `hex_cli/context/project.py`
2. Re-export project helpers from `hex_cli/context/__init__.py`
3. Regression tests: `tests/test_context_exports.py`

No dummy stubs; real implementations preserved.
