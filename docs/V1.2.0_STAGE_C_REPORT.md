## Streaming architecture
1. `on_stream_start` → `ChatLog.begin_assistant_stream()` mounts Markdown + header
2. `on_stream_token` → accumulate buffer; `update_message` with `balance_fences_for_preview`
3. `on_stream_end` → `finalize_stream` with raw text; store in session state

Not simulated typing — depends on provider stream callbacks.

## Markdown strategy
- Textual `Markdown` widget for assistant content (headings, lists, fences, etc.)
- Incomplete opening ``` balanced for preview only during stream
- Finalize uses actual buffer without forced close if already balanced

## Syntax highlighting
Provided by Textual Markdown / terminal theme (language tags on fences). Full pygments themes depend on Textual/runtime.

## Copy
- Binding: **Ctrl+Shift+C**
- Copies last complete fenced block from stream buffer or last assistant entry
- Uses `App.copy_to_clipboard`; reports failure honestly

## Scrolling
- Auto-scroll only when near bottom
- Manual scroll-up pins follow until user returns to bottom
